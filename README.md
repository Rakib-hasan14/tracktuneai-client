# TracktuneAI

**TracktuneAI** is an intelligent CV screening platform that leverages AI to help job seekers tailor their resumes to specific job descriptions. With just a job post and a resume, TracktuneAI provides a match score and actionable insights to optimize your CV for better chances in the hiring process.

---

## 🚀 Features

- 🔍 **AI-Powered CV Matching**  
  Upload a resume and paste a job description — get an AI-generated match score instantly.

- 📊 **Smart Feedback System**  
  Understand where your CV aligns or falls short against the job post.

- 🧠 **Skill & Keyword Analysis**  
  Analyze missing keywords, key skills, and qualifications using NLP.

- 💾 **Secure File Upload**  
  Upload and parse PDF resumes with privacy and security.

## 📦 How It Works

1. **Enter Job Description**: Paste the job post or description in the input box.
2. **Upload Resume**: Upload your CV as a PDF.
3. **Get Match Score**: AI evaluates the fit and returns a percentage score.
4. **Review Feedback**: View insights and tips on how to improve the match.
